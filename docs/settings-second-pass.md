# Settings second pass — workflow review and verification

2026-11-11, `feature/style`. This continues the uncommitted first pass and preserves its source baseline under `test-output/settings-second-pass/baseline/` plus hashes. Home and Reminders are protected references; no design-system reset, commit, deployment or live SavedVariables edit is part of this pass. The user deployed the previous pass themselves before this request.

The first-pass “offline complete” status was too broad as a statement of UX quality. Shared styling and construction checks did not establish Reminders-level usability for every page. This matrix supersedes that interpretation, while retaining the original evidence as history.

## Classification

- **Styled only:** shared visuals, existing workflow. This label is retained where there was no structural work; it is never counted as new UX modernization.
- **Partially modernized:** useful grouping/clarity exists, but a technical grid or optional-addon workflow still needs further review.
- **Substantially modernized:** a focused workflow, appropriate progressive disclosure and useful feedback are implemented. “Existing” cases keep an already suitable workflow; they are not claimed as new refactors.

These classify workflow implementation, not user approval or real-client acceptance. Small, already focused forms are not expanded into artificial dashboards. Expert grids are not silently relabeled as redesigned.

## Material changes and priority workflows

- Ordinary sections now use the **same walnut/card source** as Reminders Appearance, When and Sound. The shared card helper recognizes an existing face instead of installing or hiding a second face/grain. Canvas wells remain recessed. Home and Reminders source files are preserved. Player-chosen colors inside feature previews are respected.
- Twenty-one long-form pages have explicit task groups. Search/direct links select the containing task before revealing a row. Missing optional integrations do not get empty task strips. Original setting IDs, setters and dependencies remain authoritative; the added headings affect presentation rows only.
- Magic Inventory has focused Rules, Destinations, Guild arrangement and Protected items views. Rule cards show readable names, matching items, destination, keep amounts, enable state and problems. Edit is primary; move/duplicate/delete are secondary. Existing virtual dragging, four-step private editing and review/execution remain intact. Destination entry rows no longer squeeze labels, input and character scope into one line. The private item editor shows selected categories first, with the full catalog disclosed on demand. Wrapped catalog rows size from their actual labels; quality choices no longer squeeze five long labels into one row.
- Chat and hazard rules switch between their list and a focused editor. Match hints are concise; full syntax/examples remain in the match menu tooltip. Back, Save and Cancel retain their existing semantics; example syntax remains in contextual help. Glow spells similarly separates browse, Add and selected-look editing, retaining the real glow sample. Chat cleaning also discloses the long built-in filter list. Camping discloses each profession’s detailed object choices. World Knowledge puts bulk actions behind a disclosure and uses the shared painted selected-row art.
- Notifications chooses a card type before its controls. Healer Watch splits readings, thresholds, channels, appearance and testing; rare effects/position details are disclosed. Chronicle and Navigation separate the player's normal task from fine tuning.

## Preview adoption

One settings-owned companion is reused by Notifications, Healer Watch, Journey Chronicle and Navigation (seven registered pages including appearance tabs). Each family caches one private scene, at most four. It uses the existing Reminders placement, frame and connector helpers. Show/Hide is session-only. Search, leaving the page and closing settings hide it; closed refreshes cannot resurrect it. Clickable sample regions reveal their real setting without writing a saved value.

Notifications reuses NotifyLook typography/divider/backdrop helpers in an explicitly labeled compact style sample. The existing full real-position card tests remain. Healer Watch uses `HealerDisplay.NewSurface/DrawSurface` and existing made-up scenarios, with no group reads or feature enablement. Chronicle uses its actual font/surface helpers over synthetic text, never journal entries or notes. Navigation creates a private real frame renderer with a distinct frame name and made-up instructions; it never starts or changes a route. Existing world-position and arrow previews remain.

Existing appropriate inline previews and focused review windows are retained elsewhere. The matrix records the decision for every page; a new companion is not forced onto data, privacy, profile or destructive-operation settings.

Auction House and World map places deliberately remain small direct forms; Addon skins is a launcher/integration page, not a new external-addon redesign.

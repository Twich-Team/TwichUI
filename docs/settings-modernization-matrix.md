# TwichUI settings modernization progress matrix

This is the persistent page tracker. Its 58 rows reuse the second-pass classification and page decisions; they are not a new audit. Page IDs, names, workflow changes and preview suitability come from [the second-pass review](settings-second-pass.md). Screenshot and unit evidence come from the [first-pass rollout tracker](settings-modernization.md), [runtime control inventory](settings-modernization-inventory.md), and [design-system guide](settings-design-system.md).

## Status and evidence rules

- **Styled only:** shared presentation was applied; no substantial workflow redesign is claimed.
- **Partially modernized:** meaningful structure or grouping exists, but a technical grid or optional integration still needs UX or client review.
- **Substantially modernized:** the second-pass report classifies the workflow as substantially modernized. This is an implementation status, not acceptance.
- **Verified:** reserved for a page with the required automated, visual and real-client acceptance evidence. No page currently qualifies.
- **Blocked:** reserved for a named dependency that prevents progress. No page is currently blocked; optional integrations are recorded as dependencies instead.

Simulator evidence establishes construction, state and reviewed rendering within its documented limits. It does not establish actual client fonts, pointer/keyboard behavior, combat restrictions, reload persistence or installed-addon compatibility. Therefore **no page is marked Verified**.

Priority: **P1** next implementation batch, **P2** planned follow-up, **P3** retain/defer. “Next action” is proposed work only; this document does not authorize or implement it.

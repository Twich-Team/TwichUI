# F22 — Dispel Indicator Studio

Players choose a beautiful preset, choose Player, Target, Party or Raid and the
dispel types they care about, then save. An optional visual workspace lets them
place, resize and coordinate a few effect layers on a realistic frame preview.
Simple borders remain one short task; advanced designs remain purpose-built
indicators rather than a general animation environment.

**Status:** architecture and styled wireframes only. No production listeners,
overlays, editor, assets or saved-data schema changes are included. Mockups are
simulated design artifacts, not native screenshots. Main baseline:
`364c4c28889d621335bc4b3a7b61d234c0b04ce0` (2026-11-23 fetch).

## Persistence, defaults and immediate application

All table entries below use **setting IDs without the `TWICHUI_` prefix**. The registered variable is `TWICHUI_<ID>`; preserve both the ID and its setting object. [Kit.NewSetting](../../TwichUI_Settings/Kit.lua#L113) establishes that identity, page ownership and callbacks.

- **M** means `TwichUIDB.modules.<ID>`. `K.Toggle` reads `R.DEFAULT_MODULES` and routes writes through `R.Switches.Set` ([Kit.lua:342](../../TwichUI_Settings/Kit.lua#L342)); [Core.lua:80](../../!!!TwichUI/Core.lua#L80) defines the defaults. All 13 independent switches and the combat/lethal dependent switches default **false**. `qolHideErrorsKeep` alone defaults **true**, while its parent defaults false.
- **Q** means `TwichUIDB.ui.qol.<option>`, accessed only through `Q.Get/Set`. [QoL.lua:31](../../!!!TwichUI/qol/QoL.lua#L31) defines the ordered allowed values and defaults. Invalid saved choices read as the default; invalid writes are refused. Audience choices are strings; wait choices are numbers, including valid `0`.
- Both locations belong to the active profile: profile Extract/Prepare deep-copy eligible module/UI subtrees ([Profiles.lua:176](../../!!!TwichUI/Profiles.lua#L176)); `qol` and these switches are not in its account exclusion table ([Profiles.lua:32](../../!!!TwichUI/Profiles.lua#L32)). Preserve shared-profile behavior and read the active values at render/action time. There is no page draft, Save or Apply transaction.
- Non-control recovery records also exist. `ui.qol.leaveKept` remembers the two **Leave me alone** broker switches; `ui.qol.errorSpeechWas` restores the native speech CVar. Root `lootSparklesWas` and `gatheringSparklesCVars` are native-setting recovery data outside profiles. Do not rename, delete, move into row state or reset these records merely because a feature's detail closes.
- Existing friend/setup sharing intentionally keeps the automation switches and `ui.qol` local as `acts`, while display conveniences/errors are classified separately; the shareable QoL group exposes Quick Keybind only ([TwichConfig.lua:54](../../!!!TwichUI/setup/TwichConfig.lua#L54), [TwichConfig.lua:1663](../../!!!TwichUI/setup/TwichConfig.lua#L1663)). A layout change must not add settings to sharing or change backup/import policy.

## Complete explanatory, warning and prerequisite content

Keep the full tooltip/help content available as native readable text in the appropriate detail. Long duplicated paragraphs need not all appear in the overview, but their meaning must remain accessible. Selected-feature detail should show consequential behavior before or beside its controls, not require a hover-only warning.

1. **Audience interpretation, shared by offers/invitations.** Friends include character friends and WoW characters of Battle.net friends; guild membership uses the loaded guild roster; group means party or raid. Names compare without realm. Unreadable names match nobody except the explicit Anyone summon policy. [QoL helpers](../../!!!TwichUI/qol/QoL.lua#L75) implement this; do not introduce a new audience editor or broaden who qualifies.
2. **Summons.** The player arrives at the summoner's location; the native popup remains available during the wait. Only ordinary warlock/meeting-stone summons, never scenarios or skipping a starting introduction. No accept in combat or when teleporting is forbidden; the pending summon must still be the same and have time remaining; no second attempt. [Summons.lua:28](../../!!!TwichUI/qol/Summons.lua#L28).
3. **Resurrection.** Other-player offers only, respecting the native recovery delay. Resurrection sickness and Hardcore offers are excluded; soulstones/other self-resurrection, spirit healers and corpse runs are untouched, and no spirit is released. “Combat resurrection” means a visible group offerer in combat; an out-of-group offerer cannot be classified that way and counts as ordinary. The player rises with little health into the existing fight if combat acceptance is enabled. [Resurrect.lua:35](../../!!!TwichUI/qol/Resurrect.lua#L35).
4. **Release.** Battlegrounds only, never arena/dungeon/raid/open world; not Hardcore. An existing self-resurrection or offered resurrection prevents release; a new offer, getting up or entering another world cancels its pending plan. Native release permission/falling checks apply. Holding Shift when the wait ends prevents release; failure leaves the native Release button, with no retry. [ReleasePvP.lua:47](../../!!!TwichUI/qol/ReleasePvP.lua#L47).
5. **Duels.** Ordinary requests outside exceptions are declined as if clicking Decline; the challenger sees the decline. No chat or local message. Missing name is declined; lethal requests are a separately controlled event with the same exceptions. Pet-battle duel events are not handled. [Duels.lua:24](../../!!!TwichUI/qol/Duels.lua#L24).
6. **Accept invitations.** Immediate group membership; leave through the usual group menu. Already-grouped, queue-removing, role and quest-session invitations are left to the player, as are disallowed/unnamed invitations. No chat. The real queue exclusion is joining that would remove a queue, not a blanket “any queued player” rule. [Invites.lua:32](../../!!!TwichUI/qol/Invites.lua#L32). The sample caption uses broader “queued” language; do not silently convert that into changed runtime behavior.
7. **Decline invitations.** Inviter sees Decline; no chat/local message. Role and quest-session invitations are untouched. A sender allowed by the enabled Accept invitations feature is not declined, even when outside the decline exceptions; this precedence checks the accept audience, not whether accepting ultimately succeeds. Missing names are declined. [DeclineInvites.lua:35](../../!!!TwichUI/qol/DeclineInvites.lua#L35).
8. **Quick Keybind.** Adds a Game Menu button near Macros; actual insertion follows the last present utility entry (AddOns/Edit Mode/Support/Macros). It opens the game's mode with its own instructions/Okay/Cancel and changes no bindings merely by entering. Requires the native Quick Keybind frame/addon and usable Game Menu pool/anchor. The **Game Menu button**, not the QoL preference switch, is disabled in combat and shows **Not available in combat**. [QuickKeybind.lua:35](../../!!!TwichUI/qol/QuickKeybind.lua#L35), [QuickKeybind.lua:110](../../!!!TwichUI/qol/QuickKeybind.lua#L110).
9. **Group Finder zones.** Zone of the single player or group leader only, never all members; sent by the last native search. Matching the player's zone/subzone name adds a check and green text; this is not distance or proximity tracking. Insufficient row room omits the zone, and unavailable zone information does not invent a result. It does not invite, whisper, initiate searches or transmit anything. Requires the existing native Group Finder UI/hook and available listing data at runtime, not a new UI-disable prerequisite. [GroupFinderZones.lua:73](../../!!!TwichUI/qol/GroupFinderZones.lua#L73), [GroupFinderZones.lua:174](../../!!!TwichUI/qol/GroupFinderZones.lua#L174).
10. **Error hiding and speech.** Hiding removes red native error text and its associated voice/sound, while retaining yellow information, chat and TwichUI notices. Important exceptions are the four native strings enumerated at [ErrorMessages.lua:34](../../!!!TwichUI/qol/ErrorMessages.lua#L34). Independent speech silencing changes `Sound_EnableErrorSpeech`; turning it off restores the recorded native value only when still owned, preserving a manual native change. It is redundant for errors already hidden but remains a separate usable choice; it is not greyed out under Hide errors. [ErrorMessages.lua:75](../../!!!TwichUI/qol/ErrorMessages.lua#L75).
11. **Quest sparkles.** Native game-selected quest objects/NPCs only, not every pickup/herb/ore/corpse; outline settings determine sparkle versus outline. Preserve other outline/interact preferences. CVar writes/restoration wait for combat to end; graphics preset/account-synced changes may be reasserted. Turning off restores only the owned native CVar value. Removing already visible native sparkles needs a **full game restart; /reload is insufficient**. [LootSparkles.lua:60](../../!!!TwichUI/qol/LootSparkles.lua#L60), [page caveat](https://github.com/Twich-Team/TwichUI/blob/f21db0a/TwichUI_Settings/pages/QoL.lua#L264).
12. **Herb and ore sparkles.** Separate switches share the one nearby Interact Key soft target; one node at a time, within client detection range. Grey means the cursor classifies the node as ungatherable. Pause in combat and near living characters; move a few yards to resume. Both switches off restores owned interaction settings when combat permits. Unlike native quest sparkles, these overlays disappear when disabled. Pause for known highlight-addon conflicts or manual interaction-setting changes; after manual changes, turn **both** gathering options off and on to resume. No harvesting, casting, interaction or keybinding change is performed. [GatheringSparkles.lua:184](../../!!!TwichUI/qol/GatheringSparkles.lua#L184), [page help](https://github.com/Twich-Team/TwichUI/blob/f21db0a/TwichUI_Settings/pages/QoL.lua#L274).

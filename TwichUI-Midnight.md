# TwichUI: Midnight Configuration

## Custom Keybinds

| Keybind            | Action                              |
| ------------------ | ----------------------------------- |
| `CTRL + K`         | Open Clicked (Keybinding)           |
| `CTRL + S`         | Open Simulation Craft Export        |
| `CTRL + ?`         | Open BugSack (View recent errors)   |
| `CTRL + SHIFT + ?` | Clear BugSack (Clear recent errors) |
| `SHIFT + SPACE`    | Mount/Dismount                      |

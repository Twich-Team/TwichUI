# Releasing TwichUI

Open [GitHub Actions → Release TwichUI](https://github.com/Twich-Team/TwichUI/actions/workflows/one-click-release.yml), select `main`, enter the base version (for example `2.0.0`) and choose **Stable**, **Beta**, or **Alpha**, then click **Run workflow**. The single workflow checks the source and offline tests, automatically stamps and verifies all seven addon folders, generates notes, preserves the exact candidate ZIP, and publishes it to GitHub and CurseForge using the existing safe-retry publisher. For true one-click operation, the owner must **once** remove the required reviewer from the GitHub `release` environment while retaining its protected-branches restriction and `CF_API_KEY` secret; until then GitHub requires a second approval. A version whose protected tag already points to an older commit (or exists as a lightweight tag) fails safely, so the owner must resolve that tag under the protection rules or choose a newer version; the workflow never moves tags or force-pushes. Pushes and PR merges never trigger publication, and the [legacy release engineering reference](docs/release-engineering-legacy.md) remains available for incident recovery.
